# Clase práctica: gestión del tiempo y tareas

Presentación creada con Marp para publicar en GitHub Pages.

## Uso local

```bash
npm install
npm run dev
```

## Generar HTML

```bash
npm run build
```

El resultado queda en `dist/index.html`.

## Publicar en GitHub Pages

1. Crea un repositorio nuevo.
2. Sube todo el contenido de esta carpeta.
3. En GitHub, ve a **Settings → Pages**.
4. En **Build and deployment**, selecciona **GitHub Actions**.
5. Haz `git push` a la rama `main`.

## Exportar PDF

```bash
npm run pdf
```
