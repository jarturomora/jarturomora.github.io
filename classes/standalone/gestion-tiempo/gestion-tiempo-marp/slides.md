# El caso quirúrgico

La checklist no existe porque el equipo no conozca el procedimiento.

> Existe porque incluso los expertos pueden olvidar pasos críticos bajo presión.

La **WHO Surgical Safety Checklist** organiza una intervención en tres momentos:

<div class="three">
<div class="card center"><strong>Sign in</strong><br><span class="small">antes de anestesia</span></div>
<div class="card center"><strong>Time out</strong><br><span class="small">antes de incisión</span></div>
<div class="card center"><strong>Sign out</strong><br><span class="small">antes de salir</span></div>
</div>

<!--
Notas: Precisar que las checklists tienen antecedentes en aviación, pero aquí nos interesa su adopción en quirófano por la OMS.
-->

---

# Qué convierte una lista en una buena checklist

<ul class="checklist">
<li>Pasos críticos, no todos los pasos posibles</li>
<li>Redacción breve y verificable</li>
<li>Orden coherente con el momento de uso</li>
<li>Una persona responsable de confirmar</li>
<li>Uso visible, no escondido en la memoria</li>
</ul>

> Una checklist no sustituye el criterio profesional. Lo protege.

# Técnica Pomodoro

## De temporizador a sistema de aprendizaje

---

# Origen

Francesco Cirillo desarrolló la técnica a finales de los años ochenta, cuando era estudiante universitario.

Usó un temporizador de cocina con forma de tomate.

<p class="big tomato"><strong>Pomodoro = tomate</strong></p>

Pero el método no es solo “25 + 5”. También incluye planificación, interrupciones, estimación y revisión.

---

# Ciclo básico

# Regla importante

<p class="big center"><strong>El Pomodoro es indivisible.</strong></p>

Si se abandona deliberadamente la tarea, ese Pomodoro no se contabiliza como completado.

> No medimos “tiempo sentado”. Medimos atención sostenida.

---

# Laboratorio Pomodoro

<div class="timer-box" id="timer">15:00</div>

<div class="center">
<button onclick="startTimer()">Iniciar</button>
<button onclick="pauseTimer()">Pausar</button>
<button onclick="resetTimer()">Reiniciar</button>
</div>

<script>
let total = 15 * 60;
let remaining = total;
let interval = null;
function renderTimer(){
  const m = String(Math.floor(remaining/60)).padStart(2,'0');
  const s = String(remaining%60).padStart(2,'0');
  const el = document.getElementById('timer');
  if (el) el.textContent = `${m}:${s}`;
}
function startTimer(){
  if(interval) return;
  interval = setInterval(() => {
    remaining = Math.max(0, remaining - 1);
    renderTimer();
    if(remaining === 0) pauseTimer();
  }, 1000);
}
function pauseTimer(){ clearInterval(interval); interval = null; }
function resetTimer(){ pauseTimer(); remaining = total; renderTimer(); }
renderTimer();
</script>

<p class="small center">Durante el intervalo, registra interrupciones en tu hoja.</p>

<div class="card"><h3>Atención</h3><p>Cuánto tiempo puedo sostener foco real.</p></div>

# Métrica 1: estimado vs. real

<table class="table">
<tr><th>Tarea</th><th>Estimados</th><th>Reales</th><th>Error</th></tr>
<tr><td>Preparar presentación</td><td>3</td><td>5</td><td>+2</td></tr>
<tr><td>Revisar práctica</td><td>2</td><td>2</td><td>0</td></tr>
<tr><td>Leer artículo</td><td>1</td><td>2</td><td>+1</td></tr>
</table>

<p class="big center"><strong>Error = Real − Estimado</strong></p>

---

# Métrica 2: precisión de estimación

<div class="card center">
<p class="big"><strong>Precisión = Estimados / Reales</strong></p>
<p>Si estimé 4 y necesité 5:</p>
<p class="big tomato"><strong>4 / 5 = 80 %</strong></p>
</div>

<p class="small">Métrica didáctica para analizar el experimento, no una métrica oficial única del método.</p>

---

# Métrica 3: interrupciones por Pomodoro

<div class="card center">

</div>

# Métrica 4: tasa de finalización

<div class="card center">
<p class="big"><strong>Pomodoros completados / Pomodoros iniciados</strong></p>
</div>

Interpretación:

- Baja finalización: tarea mal preparada o demasiadas interrupciones.
- Alta finalización: buen encaje entre tarea, contexto y duración.

# No convertirlo en una carrera

<p class="big center"><strong>Más Pomodoros no siempre significa mejor trabajo.</strong></p>

La pregunta útil no es:

> ¿Cuántos Pomodoros hice?

La pregunta útil es:

> ¿Qué aprendí sobre cómo trabajo?
